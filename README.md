# GlobalControls

This mod will hopefully start to be included in many popular packs, and allow users to have their own default controls.  It stores all control configs in a file outside the modpack instance, meaning any pack you download that includes Global Controls will inherit your default controls on first launch.  The default location of the file depends on your os, but is configurable:

Windows: `%APPDATA%/GlobalControls/<mc-version>-controls.json`

Mac OS: `~/Library/Application Support/GlobalControls/<mc-version>-controls.json`

Linux: `~/.local/share/GlobalControls/<mc-version>-controls.json`

There are several commands to manage controls:

Set current controls globally: `/globalcontrols push <mod|all> [control|all]`

Load controls after initial launch: `/globalcontrols load <mod|all> [control|all]`

Directly set a control, leave blank to unset: `/globalcontrols set <mod> <control> [key]`

If you have any questions or issues, please open an [issue](https://github.com/kirjorjos/Global-Controls/issues) or find me on discord (kirjorjos).

> Older versions (1.7.10–1.16.5) use Java 21 with bytecode downgrade via JVM Downgrader.

### Key syntax

- **`key`** — A GLFW key name like `L`, `LSHIFT`, `SPACE`, or a combo like `LSHIFT+R`
- **`Unbound`** — Explicitly mark a control as unbound
- **Omitting `key`** — Resets to default (removes from profile)

## Mod Integrations

Due to some mods being special and storing their controls in a unique place, I've added several integrations:

| Mod | Config file | Handler |
|-----|------------|---------|
| **JEI** (Just Enough Items) | `jei/jei.toml` | `JeiHandler` |
| **REI** (Roughly Enough Items) | `roughlyenoughitems/config.json` | `ReiHandler` |
| **EMI** | `emi/emi.toml` | `EmiHandler` |
| **NEI** (Not Enough Items) | `NEIIntegration/client.cfg` or `nei/client.cfg` | `NeiHandler` |

These are registered per-loader — e.g., Fabric gets JEI + EMI + REI, while legacy Forge gets NEI only.

## Building

### Requirements

- JDK 17+ (JDK 21 recommended)
- No external dependencies — Gradle wrapper is included

### Build everything

```sh
./gradlew buildAll
```

### Build a single version example

```sh
./gradlew :fabric-1_20_1:build
```

### Collect distributable JARs

```sh
./gradlew collectArtifacts
```

JARs are copied to `build/distributions/` with standardized names like `GlobalControls-Fabric-1.20.1-1.0.1.jar`.

### Run tests

```sh
./gradlew test
```

## Adding a New Minecraft Version

1. **Add an entry** to `versions.json` under the appropriate loader family:

```json
{ "id": "fabric-1_21_1", "mc": "1.21.1", "yarn": 12, "loader": "0.16.0", "java": 21, "downgrade": false, "modVersion": "1.0.0", "shared": "fabric" }
```

2. **Run `./gradlew buildAll`** — `settings.gradle.kts` auto-generates the per-version files.

### Field reference

| Field | Required | Description |
|-------|----------|-------------|
| `id` | ✓ | Unique project identifier (e.g., `fabric-1_20_1`) |
| `mc` | ✓ | Minecraft version (e.g., `1.20.1`) |
| `loader` | ✓ | Mod loader version or Maven coordinate |
| `java` | ✓ | Java toolchain version |
| `downgrade` | ✓ | Whether to downgrade bytecode for older JVMs |
| `modVersion` | ✓ | Mod version string for this build |
| `shared` | ✓ | Shared source directory under `src/shared/` |
| `yarn` | | Yarn mapping version (Fabric only) |
| `mappings_type` | | `"mojmap"` or `"mcp"` (Forge) |
| `mappings_val1` | | MCP mapping type (e.g., `"stable"`, `"snapshot"`) |
| `mappings_val2` | | MCP mapping version |
| `platform` | | `"legacy"` for pre-Brigadier versions |
| `mcpbot` | | Add MCPBot repository |
| `mcmod` | | Use `mcmod.info` instead of `mods.toml` |
| `extra_source` | | Additional source directory (for per-version entrypoints) |
| `neoforged_maven` | | Add NeoForged Maven repository |
| `quilt_maven` | | Add Quilt Maven repository |

## Architecture

GlobalControls uses a layered platform abstraction:

1. **`platform-api`** — Interfaces (`ControlPlatform`, `CommandPlatform`, `ModPlatform`, `ExternalControlHandler`) that define how to interact with keybindings, commands, and installed mods.
2. **`platform-brigadier`** — Implementation for Minecraft 1.13+, using reflection over `KeyMapping`/`KeyMapping$KeyModifier` and Brigadier for commands.
3. **`platform-legacy`** — Implementation for Minecraft ≤1.12.2, using LWJGL2 key codes and Forge's `ClientCommandHandler`/`ICommand`.
4. **`common`** — Shared mod logic: `ControlService`, `CommandTreeBuilder`, `BindingRegistry`, `GlobalProfileService`, config management, and autocomplete.
